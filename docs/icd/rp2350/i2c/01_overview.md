# I2C: Overview & Terminology

[Back to I2C index](index.md) | [Back to ICD index](../index.md)

## 12.2.1. Features

Per controller (each instance is fully independent):

- 32-bit APB access.
- Master or slave (default: master, slave disabled at reset).
- Standard, Fast, or Fast Mode Plus speeds.
- 7-bit or 10-bit addressing in master mode (7-bit by default).
- 16-entry TX and RX FIFOs.
- Restart conditions when master (can be disabled for legacy devices).
- Configurable timing: TsuDAT, ThDAT, *_HCNT, *_LCNT, spike suppression.
- DMA interface (single transfers; low bandwidth).
- Single combined interrupt.
- Spike suppression (default 7 `clk_sys` cycles).
- Slave-mode features: NACK after RX, hold transfer when TX FIFO empty,
  hold bus until RX FIFO has space, restart-detect interrupt.

## 12.2.1.2. Clocking

All internal clocks (including the documented `ic_clk`) are sourced from
`clk_sys`. The I2C SCL frequency is generated by dividing `clk_sys` using
the `IC_*_SCL_HCNT` / `IC_*_SCL_LCNT` registers.

## 12.2.1.3. IO Requirements

For each I2C controller, route SCL and SDA to the chosen GPIO pair (Bank 0,
function code `0x03`). Pads must be configured:

- Pull-up enabled (`PUE=1`).
- Schmitt trigger enabled (`SCHMITT=1`).
- Slew rate slow (`SLEWFAST=0`).

> External pull-ups are still required on the bus. Internal pull-ups are
> not strong enough.

## 12.2.4. Terminology

### 12.2.4.1. Bus Terms

- **Transmitter** — device that sends data to the bus.
- **Receiver** — device that receives data from the bus.
- **Master** — initiates transfers (START), generates SCL, terminates
  (STOP).
- **Slave** — addressed device.
- **Multi-master** — multiple masters allowed via arbitration.
- **Arbitration** — predefined procedure choosing one master when several
  start simultaneously.
- **Synchronization** — combining masters' SCL via wired-AND.
- **SDA** — serial data line.
- **SCL** — serial clock line.

### 12.2.4.2. Bus Transfer Terms

- **START / RESTART** — SDA falls while SCL is high.
- **STOP** — SDA rises while SCL is high.

START and RESTART are functionally identical. After STOP the bus is idle.

## 12.2.5. Behaviour Summary

The DW_apb_i2c can be configured as either an I2C master only, **or** an
I2C slave only — never both at the same time. To stay master-only, ensure:

```
IC_CON.MASTER_MODE = 1
IC_CON.IC_SLAVE_DISABLE = 1
```

To stay slave-only:

```
IC_CON.MASTER_MODE = 0
IC_CON.IC_SLAVE_DISABLE = 0
```

See [`02_modes.md`](02_modes.md) for full init sequences.

### High-Level Bus Cycle (Master)

1. Master writes the slave address (with R/W bit) to `IC_TAR` (or it sits
   in the `IC_DATA_CMD` flow with a STOP/RESTART flag).
2. The first write to `IC_DATA_CMD` after enable causes a START + address.
3. Subsequent writes either send more bytes (R/W = write) or trigger reads
   (`IC_DATA_CMD.CMD = 1`).
4. When the TX FIFO drains and `STOP` was set on the last command, the
   master issues STOP and frees the bus.

## 12.2.8. Multi-Master Arbitration (informational)

If two masters START simultaneously, they arbitrate on SDA: the master
that drives `1` while the other drives `0` loses. The losing master stops
generating SCL and turns off its data driver. Slaves do not arbitrate.

For FT1 there is **one master** on each I2C bus, so arbitration is not
expected — but the driver must still handle the `TX_ABRT` interrupt and the
`ABRT_LOST` source if it ever fires (e.g., due to a stuck slave).

## 12.2.9. Clock Synchronization (informational)

Clock stretching: a slow slave (or another master) can hold SCL low; the
DW_apb_i2c master adapts and continues once SCL is released.

## 12.2.13. Bus Clear Feature (informational)

If SDA is stuck low, the master can issue up to 9 SCL pulses to flush a
hung slave then send a STOP. If SCL is stuck low, only a hardware reset
recovers. The FT1 driver should record bus-clear events for diagnostics.
